# Travel Planner («Поехали вместе»)

Веб-приложение для совместного планирования групповых поездок: единое пространство для задач, чек-листов, маршрута, расходов и автоматического расчёта долгов.

**Тип сервиса:** веб-приложение (SPA)
**Стек:** Python 3.8+ / Flask · PostgreSQL · HTML / CSS / JavaScript
**Статус:** учебный MVP в рамках проектно-технологического семинара (ЯГТУ, кафедра «Программная инженерия»)

## Запуск проекта

### Требования
- Python 3.8+
- PostgreSQL (локально)
- pip / venv

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ-ЛОГИН/travel-planner.git
cd travel-planner

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить переменные окружения
# Создайте файл .env по образцу .env.example:
# DB_USER=postgres
# DB_PASSWORD=your_password_here
# DB_HOST=localhost
# DB_PORT=5433
# DB_NAME=Travel_planner
# SECRET_KEY=your_secret_key_here

# 5. Инициализировать БД (после появления миграций/скриптов)
# psql -U user -d travel_planner -f schema.sql

# 6. Запустить приложение
python app.py
```

*После запуска приложение будет доступно по адресу `http://127.0.0.1:5000`

## Правила работы с Git

| Тип ветки | Шаблон | Пример |
|-----------|--------|--------|
| Функциональность | `feature/<НОМЕР-ЗАДАЧИ>-<краткое-описание>` | `feature/TASK-12-user-auth` |
| Исправление | `fix/<НОМЕР-ЗАДАЧИ>-<краткое-описание>` | `fix/TASK-15-login-error` |
| Документация | `docs/<НОМЕР-ЗАДАЧИ>-<краткое-описание>` | `docs/TASK-20-update-readme` |

**Правила:**
- `main` — стабильная ветка, прямые коммиты запрещены.
- Каждая задача — в отдельной ветке от `main`.
- Слияние — только через **Pull Request** с проверкой другого участника (approve).
- Номер задачи указывается **в названии ветки**, **в сообщении коммита** и **в описании PR**.

### Трассировка

Цепочка: **требование → задача в трекере → ветка → коммит → PR → результат**.

Пример:
```
Ветка:   feature/TASK-24-expense-debt-calculation
Коммит:  TASK-24: добавлен алгоритм минимизации долгов
PR:      Closes TASK-24
```

### Стек и стек-специфичные артефакты

Проект использует Python/Flask и PostgreSQL — в `.gitignore` исключены `__pycache__/`, `.venv/`, `.env`, `*.pyc`, а также служебные файлы IDE.
